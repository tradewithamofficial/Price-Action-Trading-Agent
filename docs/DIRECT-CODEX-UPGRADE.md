# Direct Codex upgrade — v1.1.0 candidate

Prepared **2026-11-03**. The existing main-window construction, icon, illustration,
theme and control layout are preserved. The three owner-supplied files in
`reference_simple` remain unchanged; default requests include their complete
analytical instructions. The reference Python runner is retained as an example.

## Architecture and validation

- One direct installed-Codex invocation per approved request, UTF-8 stdin, selected
  model and a unique final-response file. No final JSON schema or application-side
  group creation. Codex handles analysis, drawings and grouping through existing MCP.
- Exact target confirmation/symbol selection, background workers, overlap lock,
  retained logs, progress and All Charts blocking remain. The tested prompts
  require all three 1H/4H/1D; unsupported selections fail clearly.
- Before/after chart readbacks independently check existing-object preservation,
  new IDs/group membership and restored timeframe where available. Missing or
  failed readback is explicitly unverified; exit zero is insufficient.
- The full final setup response is sent through the existing safeguarded Telegram
  transport, escaped and split without discarding price/confirmation/pattern text.
  Failed or approval-blocked execution is not delivered.
- Source regression suite: **129 offline tests passed**, plus a focused direct-response
  Telegram acknowledgement integration test, including CLI arguments,
  prompt fidelity, response/timeout/failure cases, identity, preservation, mocked
  Telegram acknowledgements, native GUI controls, cancellation and background jobs.
- Windows candidate: **8 packaged checks** and **8 extracted-ZIP checks** passed,
  including actual idle EXE startup, exact compiled-source comparison, robot icon,
  transparent illustration, bundled/editable prompts, progress/log retention and
  cancelling both real dark confirmations without analysis or delivery. The ZIP
  has 111 files and all 16 third-party license texts; private-value and compiled
  content scans found no unresolved credential findings. The blank public config
  is generated by the build; local populated config/example files are excluded.
- The supplied reference runner's original extra blank line at EOF is retained.
  It is the sole new-file whitespace exception; all other changed files must pass
  Git's whitespace check. No global whitespace setting or upstream notice changed.
